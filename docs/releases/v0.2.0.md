The first public release of **Overlid**: a dynamic island for Windows with AI coding status and a notch teleprompter.

## Highlights

- **Island.** A black notch at the top of your screen that opens on hover. Alerts split it like a Dynamic Island, and it hides during full-screen games and presentations.
- **Media.** Now playing from Spotify, browsers or any app with Windows media controls, with artwork, controls and an accent colour from the cover.
- **CodeNotch.** Usage rings for Claude Code, Codex and GitHub Copilot, plus live Claude Code sessions with a "needs you" bell.
- **Teleprompter.** Scripts scroll under your webcam, hidden from screen share. Voice mode, .txt/.md/.docx/.pdf import, resizable, with global shortcuts.
- **Focus timer, Quick action, clipboard history and Stats.**
- **Security hardening.** A token-protected local hook receiver, no telemetry, redacted logs, a strict window security policy, hostile-file checks on import, and checksums for every release. See [SECURITY.md](https://github.com/Vigesh-VS/OverLid/blob/main/SECURITY.md).

The full list is in the [CHANGELOG](https://github.com/Vigesh-VS/OverLid/blob/main/CHANGELOG.md#020---2026-11-14).

## Install

1. Download **`Overlid_0.2.0_x64-setup.exe`** and **`SHA256SUMS.txt`** below.
2. Check the download. In PowerShell, in your Downloads folder:
   ```powershell
   (Get-FileHash .\Overlid_0.2.0_x64-setup.exe -Algorithm SHA256).Hash.ToLower()
   ```
   The result must match the line in `SHA256SUMS.txt`.
3. Run the installer. It installs for your user only; no admin rights are needed.

**"Windows protected your PC"?** The installer isn't code-signed yet, so SmartScreen may warn you. After checking the checksum, click **More info → Run anyway**.

Requires Windows 10 (2004 or later) or Windows 11.
