OVERLID BRAND ASSETS

The logo is reconstructed as clean SVG geometry based on the supplied reference.
It retains the metallic look of the reference while providing flat black/white
versions and a reduced micro-mark for tiny UI sizes.

source/
  Editable SVG masters: metallic, black, white, and micro variants.
website/
  Transparent logo PNGs at multiple resolutions, favicon.ico, site.webmanifest.
app/
  Transparent micro glyphs, square app tiles, Tauri-style PNG sizes, icon.ico.

Recommended:
- Website/header: source/overlid-metallic.svg or website/overlid-metallic-2048.png
- Light background: source/overlid-black.svg
- Dark background: source/overlid-white.svg
- Browser favicon: website/favicon.ico
- PWA: app/overlid-appicon-black-192.png and -512.png
- Tauri: app/icon.ico and app/32x32.png, 128x128.png, 256x256.png, 512x512.png

All PNG files use transparent backgrounds except square app tiles.
SVG masters are scalable and editable.
